## 1. Перша User Story

Як гравець, я хочу керувати автомобілем клавішами W/S або стрілками, щоб уникати перешкод.

## 2. Реалізація

У BirdScript.Awake() вимикається гравітація та обертання Rigidbody2D. Start() обчислює межі за ортографічною камерою. Update() визначає напрямок, перевіряє межі та встановлює швидкість.

## 3. Фрагмент існуючого коду

float direction = 0f;

if (Input.GetKey(KeyCode.W) \|\| Input.GetKey(KeyCode.UpArrow)) direction += 1f;

if (Input.GetKey(KeyCode.S) \|\| Input.GetKey(KeyCode.DownArrow)) direction -= 1f;

myRigidbody.velocity = new Vector2(0f, direction \* moveSpeed);

## 4. Перевірка та фіксація

Критерії: W рухає авто вгору, S — вниз, без клавіш швидкість дорівнює нулю. При одночасному натисканні напрямки компенсуються. Код відповідає цим умовам за статичним аналізом. Для підтвердження потрібно запустити SampleScene у Unity. Рекомендований commit: Implement player movement. У README слід зазначити керування та запуск; новий commit не створювався.
