**Практична робота №15  
Основи тестування програмного забезпечення**

Виконали: Радченко Дамір, Дуліпа Максим, Дідіцький Максим

Проєкт: двовимірна аркадна гра на Unity (C#)

Мета: підготувати позитивні та негативні тест-кейси.

## 1. Тест-кейси

| ID / тип | Дії                              | Очікуваний результат          |
|----------|----------------------------------|-------------------------------|
| T01 +    | Play у MainMenu                  | Відкривається SampleScene     |
| T02 +    | Утримувати W / S                 | Рух вгору / вниз              |
| T03 +    | Пройти тригер перешкоди          | Рахунок +1                    |
| T04 +    | Зіткнутися з перешкодою          | Game Over, авто зупиняється   |
| T05 +    | Pause, потім Resume              | Час 0, потім 1                |
| T06 +    | Restart                          | Сцена завантажується повторно |
| T07 −    | Натиснути W і S одночасно        | Вертикальна швидкість 0       |
| T08 −    | Утримувати W біля верхнього краю | Авто перестає рухатися вгору  |
| T09 −    | Тригер об’єкта не шару 8         | Очки не додаються             |
| T10 −    | Спробувати рух після програшу    | Швидкість авто 0              |

## 2. Результати перевірки

Статичний аналіз коду підтверджує наявність відповідної логіки для T01–T10. Фактичні результати ручного тестування: не перевірено в Unity. Особливо слід перевірити T08, оскільки контроль межі не коригує вже пройдену за кадр відстань.

## 3. Умови приймання

Гра запускається без помилок у Console, рахунок змінюється лише за потрібної події, керування та меню відповідають очікуванням.

## Висновок

Підготовлено 10 тест-кейсів; їх фактичний статус необхідно встановити після запуску гри.
