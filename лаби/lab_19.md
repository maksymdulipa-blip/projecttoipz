**Практична робота №19  
Зміна вимог та супровід програмного забезпечення**

Виконали: Радченко Дамір, Дуліпа Максим, Дідіцький Максим

Проєкт: двовимірна аркадна гра на Unity (C#)

Мета: проаналізувати нову вимогу та її вплив на гру.

## 1. Нова вимога

Як гравець, я хочу бачити найкращий результат після перезапуску гри, щоб порівнювати свої досягнення. Вимога запропонована для навчальної роботи. У наявному LogicScript зберігання рекорду відсутнє.

## 2. Аналіз впливу

LogicScript: порівнювати playerScore з рекордом та зберігати його через PlayerPrefs. SampleScene: додати текст рекорду. README: описати нову можливість. Інші компоненти руху та генерації перешкод не потребують змін.

## 3. Backlog

US8 — збереження рекорду; пріоритет середній. Задачі: додати поле bestScore, завантажити значення на початку гри, оновлювати його при перевищенні, показати в UI, перевірити збереження після перезапуску.

## 4. Регресійні тести

| Сценарій                  | Очікуваний результат |
|---------------------------|----------------------|
| Перший запуск             | Рекорд 0             |
| Результат 5 при рекорді 3 | Рекорд 5             |
| Результат 2 при рекорді 5 | Рекорд залишається 5 |
| Повторний запуск          | Рекорд збережено     |
| Прохід перешкоди          | Поточний рахунок +1  |

## 5. Документація

Запропонований запис для майбутньої версії: «Додано збереження найкращого результату». Нова функція не реалізована, тести не запускалися, оскільки вихідний код має залишитися без змін.

## Висновок

Сформовано план зміни вимог, визначено модулі та регресійні тести. Поточна версія гри залишена без змін.
