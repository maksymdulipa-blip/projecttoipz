# Практична робота №7. Проєктування структури програмного забезпечення (Class Diagram)

## Основні класи та їх зв'язки у C# / Unity

### 1. `BirdScript : MonoBehaviour`
* **Поля:**
  * `public Rigidbody2D myRigidbody;`
  * `public float flapStrength;`
  * `public GameObject gameOverPanel;`
  * `private bool isDead;`
* **Методи:**
  * `void Update()` — обробка введення гравця.
  * `private void OnTriggerEnter2D(Collider2D collision)` — відстеження влучання у `DeathZone` чи бонуси.
  * `void GameOver()` — зупинка гри та виклик панелі.
  * `public void RestartGame()` — перезавантаження сцени.

### 2. `LogicScript : MonoBehaviour`
* **Поля:**
  * `public int playerScore;`
  * `public Text scoreText;`
* **Методи:**
  * `public void addScore(int scoreToAdd)` — додавання балів за пройдені труби/монети.
  * `public void restartGame()` — менеджмент відновлення гри.

### 3. `PipeSpawn : MonoBehaviour`
* **Поля:**
  * `public GameObject pipe;`
  * `public float spawnRate;`
  * `private float timer;`
* **Методи:**
  * `void Update()` — інтервальна генерація нових труб за таймером.
  * `void spawnPipe()` — створення екземпляра префабу.

### 4. `PipeMoves : MonoBehaviour`
* **Поля:**
  * `public float moveSpeed;`
  * `public float deadZone;`
* **Методи:**
  * `void Update()` — зсув труби вліво та знищення (`Destroy`) при виході за екран.
