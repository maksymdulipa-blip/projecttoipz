# Практична робота №9. Основи Git та GitHub

## 1. Конфігурація репозиторію Unity
Для запобігання завантаженню тимчасових та системних файлів Unity у репозиторій додано файл `.gitignore`.

Основні папки, які ігноруються:
* `/Library/`
* `/Temp/`
* `/Obj/`
* `/Build/`
* `/UserSettings/`
* `*.csproj`, `*.sln`

## 2. Основні команди Git, використані в проєкті
```bash
# Ініціалізація та прив'язка до віддаленого репозиторію
git init
git remote add origin https://github.com/maksymdulipa-blip/projectknty.git

# Фіксація змін
git add Assets/
git commit -m "Додано механіку програшу при падінні та підключено GameOverPanel"

# Відправка змін у віддалений репозиторій
git branch -M main
git push -u origin main
```
