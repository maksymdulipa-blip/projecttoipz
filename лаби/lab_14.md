**Практична робота №14  
Реалізація функціональності та інтеграція**

Виконали: Радченко Дамір, Дуліпа Максим, Дідіцький Максим

Проєкт: двовимірна аркадна гра на Unity (C#)

Мета: описати взаємодію реалізованих функцій.

## 1. Реалізовані User Stories

| User Story     | Реалізація                        | Очікуваний результат                                 |
|----------------|-----------------------------------|------------------------------------------------------|
| US3: перешкоди | PipeSpawnerScript, PipeMoveScript | Перешкоди з’являються, рухаються вліво й видаляються |
| US4: очки      | PipeMiddleScript, LogicScript     | Прохід через тригер шару 8 додає 1 очко              |
| US5: програш   | BirdScript, LogicScript           | Зіткнення зупиняє авто та відкриває Game Over        |

## 2. Інтеграція

Генератор створює Pipe.prefab у випадковій позиції по вертикалі. PipeMoveScript переміщує об’єкт, PipeMiddleScript передає подію проходження до LogicScript. BirdScript при зіткненні викликає gameOver() та звуковий ефект.

## 3. Перевірка спільної версії

Перевірити посилання на компоненти в Inspector, тег Logic, тег Audio, шар 8 і налаштування Collider2D. Запустити сцену, пройти перешкоду, зіткнутися з наступною, натиснути Restart. Це сценарій локального тестування, не протокол фактичного запуску.

## 4. Git

Запропоновані commits: Add obstacle spawning; Add score trigger; Handle game over. Для командної інтеграції створити PR відповідних гілок до main, перевірити зміни та об’єднати. Фактичні PR та commits не підтверджені.

## Висновок

Описано функціональний прототип і зв’язок трьох основних User Stories на основі коду.
