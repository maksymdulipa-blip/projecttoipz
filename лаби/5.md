# Практична робота №5. Backlog User Stories із критеріями приймання

| ID | User Story | Критерії приймання (Acceptance Criteria) |
| :--- | :--- | :--- |
| **US-01** | Як гравець, я хочу, щоб гра закінчувалася при провалюванні персонажа нижче межі екрана. | 1. Під сценою розміщено тригер з тегом `DeathZone`.<br>2. При перетині тригера викликом `OnTriggerEnter2D` зупиняється час.<br>3. На екрані з'являється `GameOverPanel`. |
| **US-02** | Як гравець, я хочу збирати монетки під час польоту для збільшення рахунку. | 1. Монетка має колайдер із прапорцем `Is Trigger`.<br>2. При торканні пташки монетка зникає (`Destroy`).<br>3. Рахунок гравця в UI збільшується на задану кількість балів. |
| **US-03** | Як гравець, я хочу мати можливість перезавантажити гру після поразки. | 1. На панелі програшу присутня кнопка `RESTART`.<br>2. При натисканні викликається метод `SceneManager.LoadScene`.<br>3. `Time.timeScale` повертається у значення `1f`. |
| **US-04** | Як гравець, я хочу ставити гру на паузу під час ігрового процесу. | 1. Кнопка `PAUSE` зупиняє час та відкриває `PauseMenu`.<br>2. Кнопка `RESUME` відновлює гру. |
