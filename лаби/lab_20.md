## 1. README / опис проєкту

Двовимірна аркадна гра на Unity та C#. Мета — керувати автомобілем, уникати перешкод і набирати очки. Репозиторій: https://github.com/maksymdulipa-blip/projecttoipz

Вимоги: Unity 2019.1.12f1 (версія з ProjectVersion.txt).

## 2. Встановлення та запуск

1\. Завантажити архів проєкту або виконати git clone за адресою репозиторію.

2\. В Unity Hub додати папку проєкту та відкрити її у відповідній версії Unity.

3\. Відкрити Assets/Scenes/MainMenu.unity, натиснути Play у редакторі.

4\. Для збірки перевірити Build Settings: MainMenu — індекс 0, SampleScene — індекс 1.

## 3. User Manual

Play — початок гри. W / ↑ — рух вгору; S / ↓ — вниз. Без натискання автомобіль стоїть. За проходження відповідного тригера додається 1 очко. Зіткнення відкриває Game Over. Pause призупиняє гру, Resume продовжує, Restart перезапускає, Home повертає до меню. Quit завершує зібрану програму.

## 4. Приклад використання

Відкрити меню → Play → пройти перешкоду → рахунок 1 → зіткнення → Game Over → Restart. Це очікуваний демонстраційний сценарій за кодом, не скриншот фактичного запуску.

## 5. Структура репозиторію

У GitHub наявні Assets, Packages, ProjectSettings, а також згенеровані Library, Logs, obj/Debug. Рекомендовано додати README.md і Unity .gitignore, не включати згенеровані папки до майбутніх комітів. Репозиторій не змінено.
